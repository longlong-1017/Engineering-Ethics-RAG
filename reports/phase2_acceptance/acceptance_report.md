题目设计时刻意包含三类“陷阱”，以检验系统是否真的回答问题，而不是只命中关键词：

1. **关键词相同但回答不了**：例如 Q26 问“座谈会结果”，严格页 p12 只写“召开座谈会”的日期；Q15 问“化工事故人为因素”，严格页 p57 只有目录标题。
2. **金标页不在严格池**：例如 Q09 环境伦理四原则、Q10 公正公开三层含义、Q18 制药企业社会责任、Q28 天津港事故、Q30 彩虹桥原因。
3. **C/E/未审核证据**：例如 Q18 使用 C 类 p69，Q28 使用 E 类 p16（“6866亿元”本身有金额疑点），Q14 使用未修复 B 类 p17。

## 2. 运行与核对方法

- 检索参数：`top_k=6`，严格/扩展分别运行。
- 问答参数：`provider=local`，`allow_api=False`，使用离线原文摘录。
- 对每个检索命中页做：
  1. 文件名和物理页码是否存在于 JSON；
  2. 用 PyMuPDF 独立读取对应 PDF 页；
  3. 比较 JSON 文本和 PDF 文字层：去空白后完全一致（`exact`）或非空白字符多重集合一致（`reorder`，主要对应 B 类重排）；
  4. 检查答案引用片段能否在 JSON/PDF 中定位；
  5. 计算该页覆盖多少“预期事实组”；
  6. 人工逐题判读答案是否真正回答问题、引用页是否支持答案、失败原因。
- 所有 42 个金标页均通过 PDF 文件存在性、页码和文字层检查：34 个 `exact`，8 个 `reorder`。详见 [`gold_page_validation.md`](gold_page_validation.md)。
- 98 条答案引用全部为 `verified_exact` 或 `verified_reorder`；**文件/页码/文字层定位正确率 100%**。其中 45 条是 B 类重排页：字符集一致，但阅读顺序仍需人工抽查，因此表中标为“待复核（B类重排顺序）”。
- 但“定位正确”不等于“内容能回答问题”。

### 人工判读口径

| 判定 | 含义 |
|---|---|
| 正确（严格证据） | 答案核心事实正确，且至少一条严格合格引用页支持 |
| 正确（待人工复核） | 答案核心事实看似正确，但支持证据来自未审核/C/D/E/B 未修复页；不能算已核实 |
| 部分正确 | 回答了部分问题，但漏掉关键事实或混入无关内容 |
| 错误 | 没有回答问题、答错对象，或只给标题/目录 |
| 资料不足（正确） | 该模式池内确实没有金标正文，返回资料不足是正确行为 |
| 资料不足（误判） | 池内有金标正文或有效替代证据，系统却拒绝回答 |

## 3. 指标计算口径

| 指标 | 计算方式 |
|---|---|
| Top-k 检索命中率 | 该模式前 6 条中含金标页的题数 ÷ 该模式池内含金标页的题数；池内无金标记 N/A，不算失败 |
| Top-1 命中率 | 第 1 条命中金标页的题数 ÷ 池内含金标页的题数 |
| 答案正确率（含待复核） | （正确 + 正确待复核）÷ 30 |
| 严格证据正确率 | 判定为“正确（严格证据）”的题数 ÷ 30 |
| 资料不足漏判（false insufficient） | 池内含金标页且金标原文事实覆盖 ≥50%，系统却返回资料不足的题数 |
| 漏判率 | 漏判题数 ÷ 池内含金标页的题数 |
| 资料不足强答（false sufficient） | 池内无金标页，系统却给出答案的题数 |
| 强答率 | 强答题数 ÷ 池内无金标页的题数 |
| 综合误判率 | （漏判 + 强答）÷ 30 |
| 引用定位正确率 | 文件/页码存在且片段可在 JSON 或 PDF 文字层定位的引用页数 ÷ 全部引用页数 |
| 引用内容支持率 | 引用页正文覆盖该题 ≥50% 预期事实组的引用页数 ÷ 全部引用页数 |
| 答案证据支持率 | 有答案的题中，至少一条引用页同时满足“定位正确 + 内容覆盖 ≥50%”的比例 |
| 严格证据支持率 | 有答案的题中，至少一条严格页满足“定位正确 + 内容覆盖 ≥50%”的比例 |
| 待复核证据率 | 有答案的题中，仅由非严格页提供支持的比例；这些答案不能算已核实 |
| 无支持率 | 有答案的题中，没有任何引用页同时满足“定位正确 + 内容覆盖 ≥50%”的比例 |

> “证据正确率”在本次验收中拆成两个可核对指标：**定位正确率**（文件/页码/文字层）和**内容支持率**（引用页是否真的包含回答所需事实）。两者不能混为一谈。

## 5. 关键发现

### 5.1 检索召回不是主要瓶颈

- 严格 Top-6 93.8%，扩展 Top-6 100%。
- 42 个金标页全部存在且 PDF/JSON 一致或重排一致。
- 98 条引用全部能定位到正确文件、页码和文字层。

但“命中关键词页”与“回答问题”之间存在明显断层：引用内容支持率严格仅 22.4%，扩展 53.1%。

### 5.2 严格模式存在严重的“无证据强答”

严格池只有 81 页，14 道题在严格池内没有金标页；系统却对其中 **10 题**给出了答案，强答率 **71.4%**。

| 题号 | 严格模式实际行为 | 应有行为 |
|---|---|---|
| Q09 环境伦理原则 | 用 00-p54 目录、04-p3 章节标题等拼答案 | 资料不足 |
| Q10 公正公开三层含义 | 用 10-p2 目录、00-p60 目录等 | 资料不足 |
| Q14 工程风险人为因素 | 把 00-p57 目录、02-p8 技术因素当成人为因素 | 资料不足 |
| Q15 化工事故人为因素 | 只引用 00-p57 目录标题 | 资料不足 |
| Q16 基因检测伦理问题 | 拼入课程介绍、目录、无关定义 | 资料不足 |
| Q17 器官公正分配 | 只有 10-p2 目录 | 资料不足 |
| Q18 制药企业社会责任 | 讲工程伦理教育，非制药企业 | 资料不足 |
| Q19 调查专家为何回避冲突 | 回答“五种回避方式”，不是“为什么” | 资料不足 |
| Q26 PX 座谈会结果 | 只给 p12 的座谈会日期，没有结果 | 资料不足 |
| Q28 天津港事故 | 错误地回答青岛事故 | 资料不足 |

这是本次验收最重要的安全问题：**严格模式当前不能保证“无证据就不答”**。

### 5.3 “是什么”定义门禁造成 7 题扩展漏判

`src/qa.py` 的 `is_definition_question` 把任何包含“是什么”的问题都当成概念定义题，随后要求 `has_direct_definition`。于是：

- Q07 工程伦理学的两种理解思路是什么
- Q08 工程风险的可接受性是什么
- Q11 工程师回避利益冲突的五种方式是什么
- Q21 挑战者号的时间、地点和后果是什么
- Q23 沱江大桥的时间、地点和参数是什么
- Q29 吉化操作工违反规程的动机是什么

这些题的金标页在扩展模式中排名第 1/2，却被错误拒答。Q27 是另一种情况：金标 p5 排第 1，但覆盖率 40.2% 低于 50% 的充分性阈值，也被拒答。

- 扩展 7 题漏判：Q07、Q08、Q11、Q21、Q23、Q27、Q29。
- 严格 5 题漏判：Q07、Q11、Q21、Q23、Q27（其中 Q27 为检索未命中）。

这是“问答逻辑错误”，不是检索失败。

### 5.4 答案摘录偏向标题，漏掉关键数字/列表项

本地摘录按句子打分，但没有区分“标题”和“可回答问题的事实句”：

- **Q24 青岛事故**：金标 p15 排第 1，页面原文含“62人亡、136人伤、直接经济损失7.5亿元”，答案却只摘到“安全伦理冲突”和事件名，没有回答数字。
- **Q15 化工事故人为因素**：p26/p27 已命中，答案只摘到“7.2 化工安全事故的伦理分析”“7.2.1 人为因素”等标题，没有列出内因/外因。
- **Q17 器官公正分配**：p45/p46 已命中，答案只摘到宏观标题、一个宏观条目和微观“谁作决定”，漏掉资源有效使用、政策限制、适应证/禁忌证、生命质量、分配方式。
- **Q14/Q16** 也出现类似的“只摘到部分条目/混入无关页”问题。

这些题的金标页文字层是正确的，失败发生在答案组织层，归为“问答逻辑错误”。

### 5.5 引用定位正确，但引用“噪声”明显

- 严格 49 条引用中只有 11 条真正覆盖 ≥50% 预期事实；大量引用是目录、章节标题或关键词相近页。
- 扩展 Q01/Q02/Q03 的答案本身由严格页支持，但仍额外引用了未审核页（05-p28、10-p24、02-p14、07-p27），增加复核负担。
- 建议只把“支撑答案的句子所在页”作为引用，而不是把 Top-k 全部页面都展示为引用。

## 7. 真实结果与限制

- 本次验收没有调用 DeepSeek，因此只评估“离线原文摘录”路径；DeepSeek 路径的答案质量未被本次验收覆盖。
- 人工判读由当前助手完成，不是教师或学生人工签核；`正确/部分正确/错误` 是验收判断，不是课程官方答案。
- PDF 文字层自动核对只能证明“页面文字存在且一致”，不能证明图片、表格、箭头、地图关系被完整提取；C/E 类页仍应人工看原页。
- 30 题不是全部考点；题库刻意覆盖了严格池缺口和风险页，因此严格模式通过率偏低是题目代表性的结果，不应被解读为 81 页完全无用。
- 02 课件 p8/p9 源页重复；B 类重排页虽然字符集一致，但阅读顺序仍需人工抽查。

## 8. 建议的修复优先级（本次未改代码）

1. **P0：收紧严格模式的“资料不足”判定**。没有可支撑答案的事实句时，必须返回资料不足；不能因为 Top-k 有相似页就生成答案。
2. **P0：修正定义门禁**。只对“什么是 X / X 是什么”且 X 为短概念的问题启用直接定义检查；不要让“方式是什么/时间地点是什么/动机是什么”触发。
3. **P1：本地答案摘录按“可回答事实句”选择**。定量题优先含数字句；列举题保留完整编号项；标题/目录句只作上下文，不能作为答案句。
4. **P1：引用只保留支撑句所在页**，不要把 Top-k 中所有页面都列为参考来源；扩展模式优先严格页，非严格页必须逐条标“待人工复核”。
5. **P1：严格模式区分 A 类与 B 类修复页**。B 类重排页可以检索，但回答里应标明“B 类重排、非人工签核”，不要与 A 类同等呈现。
6. **P2：扩充严格合格页或引入 OCR/人工补录**，尤其是 04 环境伦理原则、10 生物医药伦理、07 化工事故等高频考点。
