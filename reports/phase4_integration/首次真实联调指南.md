# 首次 DeepSeek 真实联调指南

> **第六阶段更新**：页面已改为“智能混合问答（默认）/仅课件 RAG/DeepSeek 通用问答”三种模式。  
> 下面关于“严格/扩展”和勾选的步骤是历史说明；当前请在左侧选择回答模式，并用 AI toggle 控制是否调用模型。智能混合的通用知识部分会标注“未经课件核实”。

本阶段只完成离线与Mock联调，**没有授权或发送真实付费请求**。以下步骤供你确认愿意付费后自行执行；如果由Coding Agent代为调用，需要另行明确授权次数。本地测试默认禁止真实HTTP。

## 1. 先启动离线网页

在项目根目录执行：

```sh
cd ~/Projects/Engineering-Ethics-RAG
DEEPSEEK_API_ENABLED=false .venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

浏览器打开 http://localhost:8501 。此命令临时强制关闭API，即使已有环境变量或.env开启，也不能调用。端口占用时增加 `--server.port 8502` 并使用对应地址。

不需要重新创建虚拟环境或安装依赖。退出服务用 Ctrl+C。

## 2. 先运行无费用的Mock检查

```sh
.venv/bin/python scripts/phase4_mock_check.py
.venv/bin/python -m pytest -q
```

Mock脚本使用真实processed_v3检索和提示词、固定的模拟HTTP响应，不使用真实密钥、不连接DeepSeek；报告中的Mock token数不是实际计费数据。

网页先选择严格模式，提交“工程风险的技术因素有哪些？”，检查答案、文件名、物理第8页与质量提示。在“复制答案”里用文本框右上角复制图标，粘贴到本地编辑器核对文本和引用；也可下载UTF-8答案。下载来源PDF后按物理页码核对，不按幻灯片页脚编号跳转。扩展模式内容仍须按人工核对清单签核。

## 3. 仅在明确接受费用后配置真实联调

若没有 `.env`，可复制安全模板（不覆盖已有文件）：

```sh
cp -n .env.example .env
```

用本地编辑器填写真实 `DEEPSEEK_API_KEY`，不要发到聊天、粘贴到源码、输出到终端或写入Git。已有.env不需要复制；手工核对配置即可。配置建议：

```dotenv
DEEPSEEK_API_ENABLED=true
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_CONNECT_TIMEOUT=5
DEEPSEEK_TIMEOUT=30
DEEPSEEK_DAILY_BUDGET_CNY=2
DEEPSEEK_MAX_OUTPUT_TOKENS=1000
DEEPSEEK_MAX_INPUT_CHARS=16000
```

真实密钥只填本机.env的 `DEEPSEEK_API_KEY`，此示例没有密钥值。环境变量优先于.env；如果终端已设置同名变量，修改.env不能覆盖它。配置缓存于进程内，修改后必须完全停止并重启服务。首次启动若模板未改，API总开关仍为false。

本轮依据[官方Chat Completions文档](https://api-docs.deepseek.com/api/create-chat-completion/)核对了endpoint、Bearer鉴权、模型名与请求结构；现用 `deepseek-flash`，显式关闭thinking并限制输出。旧配置 `deepseek-chat` 会被本地拦截，避免用未核对的旧模型名尝试请求。实际价格和可用模型以联调当天[官方文档](https://api-docs.deepseek.com/quick_start/pricing)及账户账单为准，不在项目中硬编码单价。

**token/字符上限不是金额封顶，每日预算是估算保护。** 输入字符数不等于token数；输入、输出及缓存等实际计费依官方规则。超时/网络失败/回答截断/回退离线都可能已经发生计费，不能据“没看到答案”认定免费。

## 4. 执行一次真实请求

先确认愿意付费，再用不带强制false前缀的命令重启：

```sh
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

1. 看侧栏“已配置”、总开关状态、UTC日预算与token统计，确认预算未被暂停。
2. 选择**严格**模式和6页以内证据；先使用上面已核对的技术因素问题。
3. 打开“AI：DeepSeek RAG（关闭为离线摘录）”开关，再点击“检索并回答”。开关本身不发请求。
4. 程序会先做证据判断，无证据时直接资料不足；有证据时最多一次POST。发送问题和被选中的证据文字，不上传PDF文件。
5. 查看生成方式、token用量、引用及错误提示。若模型改写无法在原文定位，会回退离线摘录，**不代表没调用或没收费**。接口返回用量时仍显示token；发生网络错误时用量可能未知，请查账户账单。
6. AI开关保持你的选择；关闭后只走离线。页面刷新、复制、下载及清空答案不会自动重试。

每日估算预算和token统计保存在 `data/runtime/api_limits.sqlite3`，网页、CLI及重启后的进程共享；失败/未知用量保留保护预留。UTC日切换对应北京时间08:00。不要为了重试删除账本或提高预算；这会削弱本地保护。它不是账户级账单，其他设备/程序的请求不会被限制。

## 5. 完成后关闭API

把 `.env` 的 `DEEPSEEK_API_ENABLED` 改回 `false`，核对终端环境没有同名true覆盖，停止并重启网页；或直接按第1节强制离线启动。保留账本，查看DeepSeek账户实际用量与费用。

将此次联调的模型、时间、状态、token数、是否回退、逐条引用核对结果记录到新的验收记录；不记录API Key/Authorization/原始错误响应。真实连通性、真实费用、模型完整性和人工正确性要分别验收，不能用Mock结果替代。
