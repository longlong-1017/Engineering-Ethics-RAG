## 2. 检索优化

### 之前

```text
query = 设问 + 少量案例事实词
retriever hits 直接按原始分数取 Top-K
没有证据类型，理论页和相似事故页混在一起
```

在“安全原则与责任伦理”的 Mock 对照中，旧 query 命中的候选顺序为：

```text
1. 其他事故案例.pdf
2. 老师理论课件.pdf
```

其他事故叙述可能占据主要证据位置。

### 现在

```text
query = 理论关键词 + 设问核心概念 + 最多 4 个案例事实词
证据分类 = theory / similar_case / background
排序 = 理论依据 → 背景补充 → 类似案例
```

同一 Mock 对照的新结果：

```text
NEW_QUERY：安全优先 安全第一 安全原则 …… 责任伦理 工程师责任 …… 安全 原则 责任 伦理 适用 本案 事故
NEW_EVIDENCE：
S1 theory    老师理论课件.pdf 第28页
S2 similar   其他事故案例.pdf 第12页
```

理论依据被排到第一位；类似案例保留但明确标记“只能类比”。

### 理论关键词

内置可解释词表，覆盖：

- 安全优先 / 安全原则 / 公众安全；
- 责任伦理 / 工程师责任 / 职业责任；
- 风险治理 / 风险评估 / 可接受风险；
- 利益冲突 / 披露；
- 社会公正 / 公平分配；
- 环境伦理 / 可持续发展；
- 知情同意 / 隐私；
- 职业操守 / 举报。

每个设问独立提取，不把整篇长案例作为唯一 BM25 query。

### 证据类型与提示

- `theory`：理论依据，优先用于论证。
- `similar_case`：其他事故，只能类比，不能写成当前案例事实。
- `background`：教材/背景补充，不能冒充理论依据。
- 教材统一作为补充，不标为 PPT 理论。
- 无理论证据时，`CaseSolution.warnings` 显示“课件理论依据不足”，提示不能拿类似案例冒充理论依据。
- 引用仍只允许本次实际证据编号；保留真实文件名、物理页码、审核状态。

## 3. 案例事实约束

### 调用前

新增 `_case_known_facts()`：从案例中抽取明确陈述的句子，作为模型事实边界：

```text
案例已知事实（只能把这些作为当前案例事实；其他情况视为未知）
```

提示词要求模型输出：

- `known_facts_used`
- `inferences`
- `unknowns`

并对责任分析要求区分伦理责任与法律责任。

### 生成后

`_fact_flags()` 做轻量、可解释的事实越界标记：

- 案例未提供“报告”情节却断言“未向监管部门报告”；
- 案例未提供“签署/拒签”情节却断言实际签署/拒签；
- 未提供法律责任事实却直接认定刑事/民事法律责任；
- 答案中出现案例/证据都没有的数字；
- 答案过长（>900 压缩字符）；
- 引用 `similar_case` 证据时提示只能类比，不得写成当前事实。

这些是**风险标记**，不是全面事实核验，也不会自动改写模型答案。页面在答案下方/风险区显示标记，并明确提示人工复核。

## 4. 答案格式

系统提示改为：

- 每个设问先直接回答；
- 默认 3～5 个核心要点；
- 每个要点采用：

  ```text
  **（编号）小标题。** 理论原则 + 案例事实 + 分析结论
  ```

- 不重复同一理论、不为凑要点添加无关内容；
- 优先展示考试作答版，证据/风险/诊断放在折叠区；
- 每个设问独立编号，保持原始顺序。

## 6. 原测试案例三问答案质量对比

真实 API 历史回答没有保存到仓库，无法逐字做“前后同一模型输出”对比；以下为同一 Mock 案例的检索/提示/格式对照：

| 维度 | 优化前 | 优化后 |
|---|---|---|
| 检索 query | 设问 + 案例事实词 | 理论关键词 + 设问概念 + 少量事实词 |
| 证据顺序 | 原始分数排序，事故页可能第一 | 理论页优先，类似事故在后 |
| 证据标签 | 无类型 | 理论依据/类似案例/背景补充 |
| 事实边界 | 无显式已知事实 | 调用前列出案例已知事实 |
| 推断限制 | 仅要求区分 | Prompt + 越界标记 + 人工复核提示 |
| 答案结构 | 自由长段落 | 直接回答 + 3～5 个结构化要点 |
| 法律责任 | 可能直接断言 | 事实不足时标记核实 |
| 类似案例 | 可能混同当前案例 | 只能类比，引用时标记风险 |

Mock 示例的新答案形态：

```text
**（1）安全与效率冲突。** 根据安全优先原则，案例中负责人发现隐患仍决定继续施工，说明工期/成本压力被置于人员安全之上。

**（2）责任伦理要求。** 工程师应履行职业责任，对公众安全承担伦理责任；法律责任需结合具体事实进一步核实。
```

## 8. 剩余风险

- 理论词表是规则法，复杂设问可能没有命中；需要人工确认和后续扩充。
- 证据分类基于文本标记，**不是语义模型判断**；可能误把含“责任”的事故页标为理论，或把理论页标为背景；页面会显示类型供复核。
- 轻量事实标记只覆盖报告/签署/法律责任/数字等明显越界，不能证明每个句子都符合案例事实。
- 理论依据不足时模型仍可生成通用补充，但页面会标记，不应把它当课件结论。
- 真实 DeepSeek 输出未在本阶段调用；所有测试为 Mock。
- 未重建索引/向量，未修改原始 PDF、页码映射或审核状态。
- 未读取/输出 API Key；未自动提交 Git。
