# 补充修复：智能混合模式调用顺序与“安全/社会公正”关系题

日期：2026-11-08  
实际故障问题：`环境工程中的安全与社会公正有什么关系？`

页面现象：

- 回答模式：智能混合问答
- DeepSeek 已返回并消耗 573 tokens
- 严格课件证据不足
- 最终答案未生成
- 提示：严格 RAG 阶段已有一次 API 尝试，未自动扩展检索或改用通用知识

## 根因

### 1. 混合模式先调用严格 RAG 模型，后做扩展检索

旧 `_answer_hybrid`：

```text
严格 _answer_courseware()
  └─ 可能已经调用 DeepSeek
       └─ 模型拒答/引用失败
            └─ 返回“严格阶段已有 API 尝试”
                 └─ 不再扩展、不再通用
```

问题：严格和扩展两级检索没有先完成；严格阶段一次失败的模型调用浪费了本次提交的唯一调用机会。

### 2. “关系/联系”题只送一页证据

`src/evidence.py` 对 `explanation` 类问题默认只保留一页主证据。  
该问题严格页只有 p34（社会公正），而扩展页中：

- p28：环境工程中的**安全**
- p33：环境工程中的**社会公正**
- p34：严格页社会公正

旧规划只送 p34，模型缺少“安全与公正关系”的完整材料，容易拒答或生成无法被单页原文支持的总结。

### 3. 引用校验拒绝正常的开头总结句

模型常以一句“简明结论”开头，例如：

> 环境工程中的安全与社会公正是相互关联的：安全是首要责任，社会公正要求资源公平分配。

旧校验把该句当成无引用事实，直接拒绝。它没有检查这句话是否由后文实际引用的证据整体支持。

## 修复

### A. 先完成两级检索，再决定模型调用

`src/qa.py` 新增 `_retrieve_plan()`：只做检索和证据规划，不调用模型。

智能混合流程改为：

```text
严格检索 + 严格证据规划
扩展检索 + 扩展证据规划
      ↓
严格足够，且扩展没有增加互补页
  → 用严格证据调用一次 DeepSeek
      ↓
扩展提供了更多互补页
  → 用扩展证据调用一次 DeepSeek（严格页优先，未审核页标记）
      ↓
两级都没有足够证据
  → 调用一次 DeepSeek 通用知识
```

- 两级检索全部在模型调用前完成。
- 一次提交最多一次模型调用。
- 严格/扩展阶段一旦发生模型调用，不会自动再发起第二次。
- API 失败/引用校验失败时，返回本地课件回退或明确错误，不伪装成 AI 答案。

### B. 关系题合并同主题互补页

`src/evidence.py` 对“关系/联系/影响/作用/为什么”类解释题：

- 从已通过主题和正文检查的页面中最多取 4 页；
- 例如本次问题会使用：
  - p28（安全）
  - p33（社会公正）
  - p34（严格社会公正）
- 仍然优先排序严格页；扩展页保留未审核标记。

### C. 允许“由后文引用支持的简明结论”

`src/citations.py` 新增受限的总结句规则：

- 只允许**第一条实质性结论**是无引用的简明结论；
- 后文必须至少有 2 条有效引用结论；
- 总结句的数字必须出现在后文引用证据中；
- 总结句关键词覆盖率必须足够；
- 不得包含无依据的冲突、否定、绝对化限定词（如“相互冲突”“所有”“必然”）；
- 不生成、不补写 `[S#]`；最终答案里的总结句仍然没有伪造引用。

因此：

- 正常的“简明结论 + 分点引用”可以通过；
- “相互冲突”这类与证据相反、无依据的总结仍会被拒绝。
